# Mansi Vedpathak — Portfolio

A personal portfolio site built with plain HTML, CSS, and JavaScript, bundled with [Vite](https://vitejs.dev/).

## Project structure

```
Portfolio-Website/
├── index.html        entry page — markup only
├── src/
│   ├── style.css      all styling
│   └── main.js         all behavior (scroll reveal, hero animation, project modal, etc.)
├── public/
│   └── logo-elephant.png   served as-is at /logo-elephant.png
└── package.json
```

## Getting started

```bash
npm install     # one-time setup
npm run dev      # start the local dev server (with live reload)
npm run build    # produce an optimized build in dist/
npm run preview  # preview the dist/ build locally
```
